# Guide utilisateur

## Création d'un compte

1. Ouvrir la page Connexion ou l'application mobile.
2. Choisir l'inscription.
3. Saisir une adresse email, un nom affiché et un mot de passe robuste.
4. Valider le formulaire.
5. La session est créée et conservée sur l'appareil.

La connexion Google ou GitHub est également disponible lorsque les clés OAuth
sont configurées.

## Rechercher une œuvre

1. Ouvrir Recherche.
2. Saisir un artiste, un album ou un titre.
3. Choisir le type de résultat.
4. Ouvrir une fiche pour consulter ses métadonnées.
5. Ajouter l'œuvre à un statut ou à une collection.

## Bibliothèque

Les quatre statuts principaux sont :

- À écouter ;
- En cours ;
- Terminé ;
- Abandonné.

L'utilisateur peut aussi créer une collection personnalisée, choisir sa
visibilité, la renommer, y ajouter des œuvres ou la supprimer.

## Critiques et communauté

Depuis une fiche média :

1. attribuer une note ;
2. publier une critique ;
3. commenter une critique ;
4. voter sur une critique ou un commentaire ;
5. modifier ou supprimer son propre contenu.

## Réseau social

- rechercher un membre ;
- suivre ou ne plus suivre un profil ;
- consulter les abonnés et abonnements ;
- voir l'activité des profils suivis ;
- recevoir des notifications ;
- ouvrir une conversation lorsque la relation l'autorise.

## Boutique

La boutique permet de :

- parcourir les beats et packs ;
- filtrer et trier le catalogue ;
- ajouter des favoris ;
- prévisualiser une fiche produit ;
- gérer un panier ;
- confirmer une commande de démonstration ;
- publier un produit associé à son profil.

## Paramètres et confidentialité

Le web permet notamment de configurer :

- thème et langue ;
- visibilité du compte ;
- localisation ;
- préférences de notifications ;
- mots masqués ;
- blocage de membres ;
- export JSON ou CSV des données.

## Administration

Un administrateur peut :

- consulter les signalements ;
- supprimer une critique signalée ;
- mettre une critique en avant ;
- bannir ou débannir un membre ;
- modifier le rôle d'un utilisateur.
